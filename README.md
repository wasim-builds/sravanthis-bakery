## 🥐 Features

1. **Authentic Heritage Aesthetic & Design Tokens**:
   - Rich burgundy (`#56150E`, `#3A110C`), warm vanilla cream (`#F1DBBB`, `#FCF7F0`), and artisan amber (`#8B4513`, `#C86A24`).
   - Elegant typography with Google Fonts `Signika`, `Poppins`, and `Playfair Display`.
2. **Dynamic Weight & Size Swatches**:
   - Every product features real-time package swatches (`450g / 850g / 1.2kg` or `Single / Box of 4 / Box of 8`) that dynamically recalculate price, original comparison price, and discount % tags.
3. **Interactive Slide-Out Cart Basket**:
   - Dynamic animated **Free Express Shipping Progress Meter** (with threshold indicator).
   - Quantity stepper, item remover, and custom baking instruction notes.
4. **Multi-Channel Ordering**:
   - **One-Click Instant WhatsApp Ordering**: Automatically formats order items, package weights, quantities, subtotal, and customer delivery notes into a pre-filled WhatsApp message ready to send.
   - **Interactive Web Checkout Modal**: Delivery address capture, morning/afternoon/evening fresh batch delivery slot selector, payment method selection, and celebratory confetti animation!
5. **Smart Search & Filters**:
   - Real-time instant search across product titles, categories, and ingredients.
   - Dietary filters (100% Eggless, Bestsellers, Price sorting, Rating sorting).
6. **Mobile First Responsive Design**:
   - Horizontal scrolling category story bubbles with live badge counters.
   - Slide-over mobile drawer navigation.
   - Sticky floating WhatsApp customer care button with ping animation.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
bun install
# or
npm install
```

### 2. Run Development Server
```bash
bun run dev
# or
npm run dev
```

### 3. Build for Production
```bash
bun run build
# or
npm run build
```

## 📸 Categories

- **🥖 Sourdough Breads**: Naturally wild-fermented 36-hr heritage boules, rosemary olive focaccia.
- **🥐 Croissants & Flaky**: 27-layer Normandy butter croissants, dark chocolate pain au chocolat, cinnamon rolls.
- **🎂 Celebration Cakes**: Royal Belgian dark chocolate truffle gateau, Irani cardamom mawa cakes.
- **🍪 Artisan Cookies**: Brown butter & Maldon sea salt cookies, twice-baked almond biscotti.
- **🥧 Savoury Puffs**: Flaky tandoori paneer tikka puffs.
- **🌾 Millet & Healthy**: Sprouted ragi & multi-seed wellness loaves (refined flour free).
